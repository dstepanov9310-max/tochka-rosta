# Точка роста — публикация через GitHub Pages

## Публикация

1. Войдите на [github.com](https://github.com/) или создайте аккаунт.
2. Создайте новый репозиторий. Для бесплатного GitHub Pages репозиторий можно сделать публичным. Название, например: `tochka-rosta`.
3. Загрузите в корень репозитория файлы `index.html`, `manifest.webmanifest`, `sw.js` и файлы иконок из этой папки.
4. В репозитории откройте **Settings → Pages**.
5. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/tochka-rosta/`.
7. Откройте адрес на iPhone в Safari → **Поделиться** → **На экран «Домой»** → включите **Открыть как веб‑приложение** → **Добавить**.

## Данные и приватность

Приложение хранит записи, имя профиля и сценарии локально в браузере устройства. Они не отправляются в GitHub Pages. У каждого человека на своем устройстве и в своем браузере будут отдельные данные; синхронизации между устройствами нет. На одном устройстве и в одном браузере данные общие.

Ссылка на приложение публичная. Репозиторий содержит файлы приложения и демонстрационные данные, но не личные записи, которые пользователь внесет позднее. Не добавляйте в репозиторий экспортированные резервные копии JSON.
